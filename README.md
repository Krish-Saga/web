## How to Run Locally

This project now uses **npm** because it's getting bigger : )

Here's how you can run it locally:

1. Clone or download the repository.

2. Install the dependencies:

   ```bash
   npm install
   ```

   This will install Vite and the other project dependencies.

3. Start the development server:

   ```bash
   npm run dev
   ```

   This will start the Vite development server and give you a local link. Open that link in your browser, and you're good to go!

I'd also recommend learning a little about npm. It'll help you with many other things too.
